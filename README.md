# PESU POOL 🚖🎓

An app specifically designed for **PES students** to save money by pooling rides together.

---

## 🔑 Key Features
- **Login**: Only PES students can log in using their PES email ID (verified via Microsoft Azure ID).  
  ➝ No passwords are stored.
- **Raise a Pool**:  
  - Students can raise a pool **30 minutes before meetup time**.  
  - A user can create **one active pool** at a time or join one.
- **Meetup & Ride**:  
  - Decide a fixed spot to meet.  
  - Book an auto or cab from any preferred app.  
  - Save money by sharing rides.
- **Chat Box**: Built-in styled chat box to coordinate the exact meetup spot.
- **Location Sharing**: Shows the location of students who joined your pool.  
  ➝ Limited to a **2 km radius from college** (to avoid sharing home location).
- **Ride History**: Lasts for **30 days**.
- **Capacity**:  
  - Since the app is built on Free tier services it can handle upto **100 users at a time**.  

---

## 🛠️ Tech Stack
- **Framework**: Next.js (App Router)  
- **Language**: TypeScript  
- **UI Library**: React  
- **Styling**: Tailwind CSS  
- **Maps**: Leaflet & react-leaflet  
- **Map Tiles**: OpenStreetMap  
- **Database**: PostgreSQL  
- **ORM / Client**: Prisma (pg driver)  
- **Real-Time / WebSockets**: Pusher  
- **Authentication / SSO**: NextAuth & Microsoft Entra ID (Azure AD)  
- **CDNs**: jsDelivr & Cloudflare  
- **Linting & Code Quality**: ESLint
