PESU POOL
This app is specifically designed for pes students, only pes students can login and raise a pool in which they can meet at a fixed spot and book a auto or cab from any of their preferred app and go to college saving money.
to login into the app you can use your pes email id which is verified through microsoft azure id hence no passwords are stored.
the app also has a inbuilt style chat box which can be used to communicate to the exact spot to meet at.
it also shows the location of student who has joined your pool but it is limited to a radius of 2km from the college to avoid sharing location straight from your home.
A pool can be raised only 30mins before the meetup time.
A user can create a single active pool at a time or join one.
The app also has a ride history which lasts 30 days.
Since this app is built completely using free tier only 100 users can be handled at a time though upto 118 can be handled a 18 buffer size left to operate the app smoothly.
